# LX Music+ for Android

The Android app of [LX Music+](../README.md), an unofficial fork of
[LX Music](https://github.com/lyswhut/lx-music-mobile). See the [main README](../README.md) for its features, downloads and sources.

## Build

```bash
npm install
cd android && ./gradlew assembleRelease
```
