# LX Music+ desktop

The desktop (Windows, Linux) app of [LX Music+](../README.md), an unofficial fork of
[LX Music](https://github.com/lyswhut/lx-music-desktop). See the [main README](../README.md) for its features, downloads and sources.

## Build

```bash
npm install
npm run pack          # Windows x64 installer (build/)
```
